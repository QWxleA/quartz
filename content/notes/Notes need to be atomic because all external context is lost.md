[[Zettelkasten and Evergreen MOC]]

> To be able to play with ideas, we first have to liberate them from their original context by means of abstraction and respecification. –Sönke Ahrens

An atomic note should be completely self-supportive. It does not need or have any other ideas besides the main idea of the note. The meaning should be literally self-evident.  ^88ab01

At the same time, if notes get too small they might loose part of their meaning. H2O should not be made any smaller (It would no longer be water).

Because a note is so small it can be easily used in combination with other notes.
